# Security Policy

Please do not disclose security issues in a public issue, discussion, or pull request.

## Supported versions

Security fixes are provided for the latest release.

## Report a vulnerability

Use [GitHub Private Vulnerability Reporting](https://github.com/cfuentessalgado/lazymeili/security/advisories/new) to report a vulnerability privately.

Include the affected version, impact, reproduction steps, and any suggested fix. You can expect an initial response within seven days. Please allow time for a fix before you disclose the issue publicly.
